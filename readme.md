# Épreuve finale: Club de voyage
## Concevoir un site Wordpress pour un club de voyage
### Auteur: Sophie Nadeau
Le projet consiste en la création d’un site web dynamique et interactif pour un club de voyage, utilisant la plateforme WordPress.

Pour l'épreuve finale, l'Ajout d'une page modèle pour consulter les plus belles destinations de voyage par pays à été ajoutée.
